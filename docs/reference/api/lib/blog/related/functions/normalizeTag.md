# Function: normalizeTag()

> **normalizeTag**(`tag`): `string`

Normalizes a tag string by lowercasing and stripping non-alphanumeric characters,
allowing "Web Workers" and "web-workers" or "CDISC ODM" and "cdisc-odm" to match.
