# Function: drawInt()

> **drawInt**(`seed`, `drawIndex`, `bound`): `number`

An integer in [0, bound) at `drawIndex` for `seed`. Throws on a bound
below 1 or a negative or fractional draw index, which are programming
errors rather than player input.
